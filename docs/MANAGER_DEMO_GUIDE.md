# Как показать Elite Task менеджерам

## 1. Что отправить перед встречей

Отправьте презентацию `deliverables/Elite_Task_для_менеджеров_v2.pptx` и четыре изображения в следующем порядке:

1. `docs/screenshots/login-desktop.png` — первое знакомство и варианты аккаунтов.
2. `docs/screenshots/home-light-desktop.png` — полный рабочий день на большом экране.
3. `docs/screenshots/home-light-mobile.png` — тот же сценарий на телефоне.
4. `docs/screenshots/calendar-dark.png` — календарь, события и расчёт рабочих дней.

Не отправляйте реальные данные сотрудников, токены, `.env`, адрес production-сервера и рабочие пароли. Для показа используйте только демонстрационные аккаунты.

## 2. Готовые подписи к изображениям

### Экран входа

> Elite Task работает как корпоративный и как личный таск-менеджер. После входа сотрудник видит только доступные ему проекты и задачи.

### «Мой день» на компьютере

> Главная страница показывает ритуал, загрузку дня, дедлайны и приоритетные задачи. Руководитель получает быстрый обзор без ручной сверки нескольких списков.

### «Мой день» на телефоне

> Мобильный интерфейс сохраняет основные функции: задачи, календарь, проекты и входящие. Нижнее меню рассчитано на ежедневную работу одной рукой.

### Календарь

> В календаре объединены события и задачи со сроками. Дополнительно можно рассчитать дату через календарные или рабочие дни.

## 3. Сообщение для Telegram или почты

> Коллеги, подготовили локальную версию Elite Task. Приложение объединяет задачи компании, личный рабочий день, календарь и уведомления. Внутри действуют отдельные права руководителя, администратора и менеджера. Посмотрите короткую презентацию и скриншоты. На пилоте проверим, насколько удобно планировать день, контролировать сроки и работать с проектами.

## 4. Сценарий демонстрации на 5–7 минут

### 0:00–0:40. Задача продукта

- Сотруднику нужен один список назначенной работы.
- Руководителю нужны сроки, статусы и загрузка команды.
- Проекты и личные задачи не должны создавать дубликаты.

### 0:40–1:30. Вход и роли

- Покажите экран входа.
- Объясните роли `leader`, `admin`, `manager` и `personal`.
- Подчеркните, что права проверяет сервер.

### 1:30–3:00. «Мой день»

- Покажите утренний ритуал и напоминание.
- Объясните показатели загрузки и фокус дня.
- Откройте приоритетную задачу и покажите срок, статус, чек-лист и комментарии.

### 3:00–4:00. Проекты и команда

- Покажите участников проекта и список задач.
- Объясните, что менеджер видит только доступные проекты.
- Для руководителя покажите командную аналитику и детализацию сотрудника.

### 4:00–5:00. Календарь и входящие

- Покажите задачи и события за выбранный период.
- Рассчитайте дату через рабочие дни.
- Покажите уведомления и изменения статусов.

### 5:00–6:00. Что готово и что дальше

- Локальный MVP работает на FastAPI, Expo React Native и SQLite.
- Backend-тесты, TypeScript, Expo Doctor, Android export и Web export проходят.
- Перед production нужны PostgreSQL, TLS, резервное копирование и мониторинг.

## 5. Как сделать новые скриншоты

### Подготовка приложения

1. Запустите API командой из `README.md`.
2. Запустите web-клиент: `cd apps/mobile`, затем `npm run web:lts`.
3. Откройте `http://localhost:8081`.
4. Используйте демонстрационные данные и нейтральные названия задач.
5. Перед снимком закройте лишние окна, уведомления системы и панели разработчика.

### Desktop

- Разрешение окна: 1440×900 или 1600×900.
- Масштаб браузера: 100%.
- Формат: PNG.
- Windows: `Win + Shift + S`, затем выберите окно приложения.
- Не обрезайте боковое меню, заголовок и основные показатели.

### Телефон

- Используйте вертикальный экран без поворота.
- Android: питание + уменьшение громкости.
- iPhone: боковая кнопка + увеличение громкости.
- Не закрывайте нижнюю навигацию и плавающую кнопку создания.

### Имена файлов

Используйте понятную схему:

```text
screen-login-desktop-light.png
screen-my-day-mobile-dark.png
screen-project-manager-light.png
screen-calendar-desktop-dark.png
```

## 6. Какие кадры нужны для обновлённой презентации

Минимальный набор:

1. Вход.
2. «Мой день».
3. Список задач с фильтрами.
4. Карточка задачи.
5. Проект и участники.
6. Панель команды.
7. Календарь.
8. Входящие или настройки.

Для каждого экрана подготовьте один основной кадр. Не отправляйте несколько почти одинаковых снимков.

## 7. Что нельзя обещать на пилоте

- Production push-уведомления пока не подключены.
- Повторяющиеся задачи и зависимости ещё не реализованы.
- Диаграмма Ганта и шаблоны проектов находятся в плане следующих этапов.
- Текущая SQLite и локальное хранилище файлов предназначены для локального MVP.
- Production-деплой начинается после получения сервера, домена и SSH-доступа.

## 8. Вопросы для обратной связи

1. Понятно ли, где смотреть задачи на сегодня?
2. Хватает ли информации в карточке задачи?
3. Удобны ли статусы и обязательная причина ожидания?
4. Нужен ли отдельный обзор по проектам или сотрудникам?
5. Какие уведомления действительно важны?
6. Какие поля задачи используются каждый день?
