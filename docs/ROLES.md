# Роли и права доступа

Все правила проверяет сервер. Клиент только прячет кнопки, которые всё равно вернули бы 403.
На каждое правило есть тест в `apps/api/tests`.

## Роли

| Роль | Кто это | Как появляется |
|---|---|---|
| `leader` | руководитель компании | создаётся администратором или сидом |
| `admin` | администратор | создаётся сидом |
| `manager` | сотрудник компании | создаётся руководителем или администратором |
| `personal` | личный аккаунт | открытая регистрация `POST /auth/register` (если `ALLOW_REGISTRATION=true`) |

`leader` и `admin` вместе называются «руководство компании» (`is_company_manager`).

## Проекты

| Действие | Кто может |
|---|---|
| Создать проект компании | только `leader` или `admin` |
| Создать личный проект | любой. Для роли `personal` флаг `is_personal` всегда `true`, даже если передать `false` |
| Управлять личным проектом (переименовать, архивировать, участники) | только владелец |
| Управлять проектом компании | `leader` и `admin` |
| Добавить участника | `{user_id}` или `{email}`. Человека с ролью `personal` нельзя добавить в проект компании |
| Удалить владельца из проекта | никто (422) |

## Задачи

- **Видимость.** Менеджер видит только задачи, в которых участвует сам: он автор, ответственный или соисполнитель. Список «Мои задачи» у всех строится по этому же правилу.
- **Редактирование** (`ensure_task_editor`):
  - в личном проекте — любой участник проекта;
  - `leader` и `admin` — всегда;
  - в остальных случаях — участник задачи.
- **Ограничения менеджера.** В задаче компании, если менеджер не является одновременно автором и ответственным, он может менять только `status`, `waiting_reason`, `is_favorite` и `estimate_minutes`.
- **Статус «Ожидание»** требует непустой `waiting_reason`.

## Календарь

В календаре видны личные события пользователя и события проектов, в которых он участник. Чтобы создать событие с `project_id`, нужно быть участником этого проекта, иначе 403.

## Команда

`/team/*` — только `leader` и `admin`. Email других людей в ответах API раскрывается только руководству компании.

## Привычки (ритуал)

- Привычки принадлежат только своему владельцу. Чужая привычка — 404.
- Нельзя отметить будущий день или день старше 7 дней (422).
- Серии считаются в часовом поясе пользователя. Часовой пояс (IANA) клиент берёт с устройства и передаёт при входе.
